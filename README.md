# 超声随身智能体 (Ultrasound Portable Agent)
一个基于扣子平台搭建的医疗AI智能体原型，模拟便携超声设备的扫查、报告、随访全流程。

**核心能力**：
- 自然语言指令理解
- 病灶识别与结构化输出
- 自动生成超声报告
- 定时随访提醒

**实现平台**：扣子

**主要文件**：
- `bot-config.json`：智能体配置文件，定义了人设、回复逻辑和技能关联。
- `workflow-ultrasound.zip`：核心工作流文件，包含“超声扫查”和“随访提醒”两个工作流节点。

**关键收获**：
- 验证了“随身智能体”在医疗场景的可行性
- 打通了从感知、规划到主动服务的智能体闭环
- 积累了AI Agent产品设计的实战经验
